# VISA Vulture

VISA Vulture is a Python GUI application for controlling VISA-compatible test equipment. Load test plans from CSV files, execute them against power supplies and signal generators, and monitor results through real-time plots and logging.

## Key Features

- Connect to power supplies, signal generators, and other VISA instruments
- Define test sequences in simple CSV files
- Monitor execution with real-time voltage/current and frequency/power plots
- Run in simulation mode without any hardware
- Extend with custom instrument definitions
